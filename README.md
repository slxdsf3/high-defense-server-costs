## 高防服务器到底在防什么

高防服务器防的是 DDoS（分布式拒绝服务）和 CC 这类流量攻击。行业里通常把单机硬防能力超过 50G 的服务器叫高防服务器，能实时防护 SYN、UDP、ICMP、HTTP GET Flood 等协议层攻击，高防机房一般还配 T 级带宽和流量清洗设备。

攻击的原理不复杂：SYN 攻击利用 TCP 协议缺陷发送大量半连接请求，服务器要为每个请求维持 30 秒到 2 分钟的等待状态，数量一多内存和 CPU 就被耗光；UDP 攻击更麻烦，攻击包长得和正常数据一样，很难直接过滤。防御的核心手段是流量牵引——把进入机房的流量引到清洗中心，丢弃恶意部分，正常流量再回源到你的服务器。

有一点必须提前说清楚，这也是很多卖高防的页面不会主动告诉你的：DDoS 攻击只能被减弱，无法被彻底消除。任何“绝对防不住打”的承诺都不成立，你买到的是“被打之后业务还能活着”的能力，而不是“永远不被打”的保险。

## 选高防服务器，先看这四个参数

**防御值**。这是最容易被玩数字游戏的地方。看三个细节：一是口径，是单机防御还是机房集群总防御——三五网络明确标注“200G 单机防御”，这种单机口径才算数；二是 UDP 洪水的处理能力，比如三五网络同款套餐标注“可封堵 UDP”，指的是具备过滤 UDP 攻击流量的能力，这反而是加分项，但游戏业务用的 UDP 协议流量和 UDP 攻击流量在清洗时怎么区分，下单前值得问清楚；三是 CC 防御，CC 攻击打的是应用层，和网络层 DDoS 是两套逻辑，有些套餐抗 DDoS 但不抗 CC。

**带宽和流量**。防御值再高，出口带宽小照样堵死。国内高防套餐常见 30M–70M 独享带宽，Sharktech 的做法不一样：独服一律 10Gbps 端口起步，每月 300TB 流量包含在内。这两类口径放在一起对比时要注意，10Gbps 是端口连接速度，实际吞吐取决于流量路径和工作负载，官网自己也是这么标注的。

**IP 数量**。独服行业标配 /29 IPv4（5 个可用 IP），Sharktech 也是这个规格，IPv6 免费分配。IP 被打死后能不能免费换、换几次，下单前值得问一句客服。

**计费周期和续费价**。月付还是年付差价可能很大，这部分下面单独算账。
